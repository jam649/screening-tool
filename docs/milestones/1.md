# Milestone 1 — scaffold and secure first run

Built Python 3.12/FastAPI backend, React 18/Vite frontend, pinned dependency locks, single-service Compose deployment, multi-stage non-root image, MIT license, DCO contribution workflow, and agent guidance. Alembic baseline creates all eleven design tables plus sessions and durable login-attempt records. Per-hit party and list-entry snapshots preserve historical evidence.

## Verified

- Eleven backend integration tests pass. They cover first-admin races/acknowledgment, argon2id, Secure/HttpOnly/Lax sessions, CSRF/origin rejection, inactive users/roles/session expiry, persistent login throttling, baseline schema, immutable audit ORM/SQL/REPLACE protection, hit snapshots, and SPA routing.
- Ruff and mypy pass; Alembic reports no schema drift, migrations repeat safely, and the built wheel includes migrations.
- `pip-audit` and npm install audit report no known vulnerabilities.
- Frontend lint, TypeScript and production build pass. Three mocked browser tests pass.
- `docker compose up -d --build --wait` creates a healthy container and database volume.
- The real Playwright gate passed against that fresh container: protected route opens setup; exact backend ITA notice is shown; checkbox acknowledgment is mandatory; the first Admin is created; secure cookie flags are correct; authentication survives reload; logout and subsequent sign-in persist across reload.
- Screenshots were captured and visually inspected on the Mac under Desktop/screenshots/screening-tool/milestone-1-{setup,disclaimer,overview}.png.

## Decisions and limits

`AGENTS.md` replaces the obsolete workflow-specific `CLAUDE.md`, per current user instructions. The exact ITA statement comes from https://developer.trade.gov/terms-of-service rather than treating the design's summary wording as verbatim government text.

UI uses the requested 21st workflow. Its public onboarding-checklist component informed the compact progress layout; provenance is recorded in `.21st/design.json`. Hosted sketch generation was temporarily unavailable; safe catalog retrieval and local adaptation completed the interface. A requested private source review at 21st was blocked by automatic approval review; no source was sent for that rejected call. This did not affect implementation or browser verification.

Remote installations require TLS because session cookies are Secure; local development uses localhost. Encryption protects stored secrets but not the database volume, which belongs on an encrypted disk. Subsequent milestones add the remaining product features; this gate makes no claim about them.
